## 1. 总体概述
### 目标
输入英文单词，自动匹配可用趣味记忆方案；支持多方案组合输出、按人群动态调整权重，辅助用户快速记忆单词拼写与词义，并能解释"为什么这样记"。

### 适用场景
- 单词详情页（单个单词）：1~3 条高质量记忆方案
- 批量单词学习模式：4~10 条主题串联记忆
- 错题本复习模式：弱词强化记忆，优先选择高效方案

### 人群分层（精细化）
| 人群 | 偏重方案 | 弱化方案 | 文案风格 |
| --- | --- | --- | --- |
| 低龄小学生（6~9岁） | 谐音、顺口溜、图像场景、TPR动作、字母象形 | 词根词缀、词源 | 短句、画面感强、拟人化 |
| 小学高年级（10~12岁） | 复合词、词中词、形近对比、词族 | 复杂词源 | 联想故事+逻辑拆解 |
| 初高中/成人 | 词根词缀、词源、形近对比、词中词、创意拆分 | 顺口溜、字母象形 | 逻辑推导+词义溯源 |

### 记忆方法适配原则（认知心理学基础）
1. **荒诞原则**：越荒诞、越反常识的画面越容易被大脑记住
2. **多感官原则**：视觉+听觉+动作+情绪叠加，记忆效果倍增
3. **个性化原则**：与用户生活/兴趣相关的联想，记忆留存率最高
4. **解释原则**：能解释"为什么这样记"的方案，比单纯口诀更长效
5. **情境原则**：在语境中记忆的单词，比孤立记忆更易调用

## 2. 单词分类前置逻辑（核心新增）
> **关键洞察**：不同单词应走不同记忆路径。先分类，再匹配方法，避免"一把抓"。

### 2.1 按词长分类
| 词长 | 代表词 | 首选方案 | 备选方案 | 禁用方案 |
| --- | --- | --- | --- | --- |
| 1~3 字母 | go, do, see, bee | 场景造句、TPR动作、字母象形 | 押韵顺口溜 | 词根拆分、复合词拆分 |
| 4~6 字母 | book, water, happy | 复合词、词中词、形近对比、词族 | 谐音、场景 | 复杂词源 |
| 7~10 字母 | transport, beautiful | 词根词缀、创意拆分、词源 | 谐音分段 | 顺口溜 |
| 11+ 字母 | international, characteristic | 词根词缀 + 创意拆分组合 | 分段记忆 | 整体谐音 |

### 2.2 按词性分类
| 词性 | 代表词 | 首选方案 | 备注 |
| --- | --- | --- | --- |
| 具象名词 | apple, elephant | 图像场景、字母象形、主题归类 | 优先可视化 |
| 抽象名词 | freedom, honesty | 词根词缀、近反义、语境造句 | 必须搭语境 |
| 动作动词 | run, jump, write | TPR动作、场景造句、图像场景 | 身体记忆最强 |
| 状态动词 | exist, belong | 语境造句、近反义、词源 | 抽象度高 |
| 形容词 | big, beautiful, hot | 形近对比、近反义、场景联想 | 对比记忆高效 |
| 副词 | quickly, happily | 词族（-ly 后缀）、近反义 | 拆后缀即可 |
| 功能词 | of, the, to | 高频搭配、语境造句 | 不强求记忆方法 |

### 2.3 按可拆解性分类
- **强可拆**：有公认词根词缀 → 走规则1（词根词缀）
- **中可拆**：含熟词片段 → 走规则2（复合词）或规则3（词中词）
- **弱可拆**：无标准词根，但有创意拆分空间 → 走规则12（创意拆分）
- **不可拆**：极短词、不规则变化词 → 走规则6（图像场景）或规则10（短句造句）

## 3. 方案优先级调度策略
> 优先级在分类基础上动态调整，并非固定顺序。

### 3.1 默认匹配顺序（从高到低）
1. 词根词缀记忆法（强可拆中长词首选）
2. 复合词拆分记忆法（中长词且可切两段熟词）
3. 词源故事记忆法（长难词、有历史来源）
4. 创意拆分记忆法（无标准词根但有创意空间）
5. 词中词寻宝记忆法（内嵌熟词）
6. 形近词对比记忆法（拼写近似词）
7. 词族联动记忆法（有派生词的词）
8. 谐音联想记忆法（读音匹配通顺）
9. 图像场景联想记忆法（具象词）
10. TPR身体动作记忆法（动作动词）
11. 字母象形记忆法（低龄+具象）
12. 成对关联记忆（近义/反义）
13. 主题归类打包记忆（批量场景）
14. 字母特征记忆法（重复字母/特殊组合）
15. 拼读规则记忆法（符合拼读规律）
16. 短句微型故事串联记忆
17. 押韵顺口溜记忆（低龄专属）
18. 情绪锚定记忆法（荒诞反差）
19. 记忆宫殿空间记忆法（批量场景）
20. 首字母缩写记忆法（多词组合）

### 3.2 输出策略
- **单个单词**：默认返回 2~3 条不同类型方案（去重）
- **同一类型**：最多输出 1 条，避免重复
- **覆盖维度**：至少包含 1 条"逻辑型"（词根/拆分）+ 1 条"画面型"（场景/谐音/TPR）
- **用户偏好**：用户可关闭某类方法（如讨厌谐音），后端动态过滤

## 4. 二十大记忆规则完整定义

### 规则1｜词根词缀记忆法（长效记忆 · 一级方案）
**定义**：利用英语构词单元：前缀、词根、后缀拆解单词，通过构词逻辑理解词义，适合中长单词。

**判定条件**
1. 单词可切分为「前缀+词根+后缀」结构
2. 词库具备标准词根词缀释义
3. 严禁虚构词缀

**生成逻辑**
1. 拆分单词结构
2. 分别解释前缀/词根/后缀含义
3. 组合推导单词本义
4. 可选增加通俗联想话术

**示例**
- `unhappy = un(不) + happy(开心) → 不开心`
- `transport = trans(跨越) + port(搬运) → 跨地域搬运→运输`
- `prediction = pre(提前) + dict(说) + ion(名词) → 提前说出来的话→预言`

**约束边界**
1. ≤4 字母短词不优先启用
2. 不规则外来词汇不强行套用
3. 严禁编造不存在词根、词缀
4. 拆分后每段必须有**公认释义来源**

---

### 规则2｜复合词拆分记忆法（高通用 · 一级方案）
**定义**：单词由两个独立完整英文单词拼接构成，拆分后借助熟词理解整体词义。

**判定条件**：单词可切分为两段，两段均为合法独立英文词汇。

**生成逻辑**：单词 = A单词 + B单词；分别释义，构建联想串联词义。

**示例**
- `pineapple = pine(松树) + apple(苹果) → 菠萝`（松果样的苹果）
- `bedroom = bed(床) + room(房间) → 卧室`
- `rainbow = rain(雨) + bow(弓) → 雨后像弓的彩带 → 彩虹`

**约束边界**
1. 拆分片段必须为标准词汇，禁止无意义切割
2. 区分复合词与普通单词（mother 不能拆 mot+her）
3. 三段及以上复合词需判断语义是否通顺

---

### 规则3｜词中词寻宝记忆法（内嵌熟词联想）
**定义**：单词字符串内部包含高频熟词，利用已知熟词搭建联想桥梁。

> 区分：复合词是词源本身拼接；词中词仅字符串包含，词源不一定相关。

**判定条件**：目标单词存在连续子串为常用基础单词。

**生成逻辑**：提取内嵌熟词，编写简短故事关联单词整体含义。

**示例**
- `friend 内含 end（终点）`：真正的朋友不会走到终点
- `season 内含 sea（大海）`：大海有涨有落，季节也周而复始
- `listen 内含 list（清单）`：听别人念清单

**约束边界**
1. 优先匹配 ≥3 字母内嵌词
2. 规避 a/an/is 等超短虚词
3. 联想故事必须与单词本义强相关，不可生硬

---

### 规则4｜形近词对比记忆法（防混淆专用）
**定义**：筛选拼写高度近似、仅相差1~2个字母单词，成对捆绑，标记差异点区分记忆。

**判定条件**
1. 单词长度相同或相差1
2. 编辑距离 ≤ 2
3. 词汇属于高频词库

**细分类型**
1. 增字母：plan → plane(+e)
2. 减字母：through → though
3. 字母调换：quiet / quite
4. 单字母替换：cat / bat / mat

**生成逻辑**：高亮差异字母，搭配区分联想口诀。

**示例**
- `adapt v.适应 / adopt v.收养`：adapt 中间 a（adjust 调整→适应），adopt 中间 o（own 拥有→收养）
- `quite / quiet`：quiet 多了个 e，e 像一个人坐着很安静

**约束边界**
1. 单次对比单词数量不超过3个，避免信息过载
2. 差异字母必须赋予**视觉化提示**（字母象形或发音联想）
3. 优先同难度、同频次的对比词

---

### 规则5｜谐音联想记忆法（强趣味 · 短时记忆）
**定义**：利用单词读音与中文发音近似，构建画面联想辅助记忆拼写。

**判定条件**：音标读音匹配通顺中文谐音；读音差距过大直接放弃。

**生成逻辑**：提取谐音，搭配简短故事绑定单词释义。

**示例**
- `ambulance /ˈæmbjələns/ 俺不能死 → 救护车`
- `pest /pest/ 拍死它 → 害虫`
- `family /ˈfæməli/ 爹妈咪 → 一家人`

**强制约束**
1. 必须附带提示：谐音仅辅助记忆拼写，不可模仿发音
2. 禁用低俗、负面、违和谐音
3. 不可单独作为唯一记忆方案，尽量搭配其他方法
4. 多音节单词可**分段谐音**，每段对应一个画面元素
5. 优先使用**标准音标发音**做谐音，不要用中式错误读音

---

### 规则6｜图像场景联想记忆法（右脑画面记忆）
**定义**：不拆分拼写，围绕词义构建可视化场景画面。

**判定条件**：名词、动作动词、具象形容词优先；抽象词汇不单独使用。

**生成逻辑**：构造画面：人物 + 动作 + 环境。

**示例**
- `elephant`：长鼻子、大耳朵的巨型大象
- `umbrella`：下雨天撑开雨伞遮挡雨水

**约束边界**
1. 抽象词汇（freedom、honest）建议搭配其他记忆方案
2. 画面须具象：人物、动作、物品至少三要素
3. 可配合简笔画图标增强视觉锚点

---

### 规则7｜成对关联记忆（反义词 / 近义词）
#### 7.1 反义捆绑记忆
- 判定：词库存在标准反义词
- 逻辑：成对记忆，建立对立关联
- 示例：hot ↔ cold；buy ↔ sell

#### 7.2 近义捆绑记忆
- 判定：词义高度相近
- 示例：happy / glad；big / large

**约束**：优先高频词汇，不一次性罗列大量近义词造成混淆；并给出**细微差别**的简短说明。

---

### 规则8｜主题归类打包记忆（批量学习专用）
**定义**：同一主题单词组成词汇集合，适合批量背诵场景。

**判定条件**：批量记词模式开启；单词详情页可作为「同类词汇推荐」拓展。

**常见分类维度**：动物、食物、方位、情绪、交通工具、职业、颜色、自然、学科、家庭、节日等。

**输出形式**：【同类词汇】tiger、lion、rabbit、monkey

**约束**：单次输出不超过 10 个词，避免过载。

---

### 规则9｜字母特征记忆法（补充备用方案）
**定义**：利用单词字母特征：重复字母、首尾特征、特殊字母组合。

**示例**
- `banana` 多次重复字母 a
- `see` 两个 e，代表两只眼睛→看见
- `book` 中间两个 o，像两只眼睛在看

**约束边界**：仅作为补充方案，不单独主推展示。

---

### 规则10｜短句/微型故事串联记忆
两种模式：
1. 单词基础短句造句：`cat：The cat likes fish.`
2. 多单词串联小故事（仅批量模式启用）

**判定条件**：批量单词学习场景；单个单词页面仅作拓展内容。

**约束**：故事简短（1~3 句），画面感强，与词义强相关。

---

### 规则11｜押韵顺口溜记忆（低龄小学生专属）
**定义**：利用英文尾音押韵编写简易短句，朗朗上口。

**示例**：bee & tree：I see a bee fly to the tree.

**约束边界**：成人模式降低权重，优先展示逻辑类记忆方案。

---

### 规则12｜创意拆分记忆法（V2 核心增强）
**定义**：当单词无标准词根时，人为拆分成**认识单词 + 字母组合**，每段赋予联想，最后拼接成完整意思。

**适用场景**：无标准词根的中长单词、用户学过的熟词片段。

**✅ 创意拆分规则**
1. 拆出片段必须是以下任意一种：
   - **认识的完整单词**（fam → family 家庭）
   - **常见字母组合**（-tion, -ing, -ly, -er）
   - **字母发音片段**（re, er, or 的发音联想）
   - **象形字母**（s 像蛇、t 像伞柄）
2. 每个片段给一个小联想
3. 拼接成完整画面/故事
4. **必须明确标注**："⚠️ 创意拆分，非官方词根"，避免用户当成正规词源

**❌ 禁止行为**
1. 为了拆分把单词字母删减、调换顺序
2. 拆出的片段与单词本义完全不相关
3. 拆分后片段之间无逻辑关联

**示例**
- `famine /ˈfæmɪn/ n.饥荒`：fam(family 家庭) + ine → 家庭没粮食 → 饥荒
- `island /ˈaɪlənd/ n.岛屿`：is(是) + land(陆地) → 是一块独立陆地 → 岛屿
- `danger /ˈdeɪndʒə/ n.危险`：dang(当) + er → 当心！有危险

**约束边界**
1. 拆分片段优先选择 **≥3 字母**的熟词
2. 同一单词最多拆分 3 段
3. 必须给出**整体联想故事**，不能只列片段

---

### 规则13｜词源故事记忆法（V2 从扩展提升为核心）
**定义**：基于单词的真实历史来源编写简短故事，帮助理解词义演化。

**判定条件**
1. 单词有公认的词源（拉丁语、希腊语、古英语等）
2. 词源故事简短易懂
3. 适合长难词、有历史来源单词

**生成逻辑**
1. 查找单词真实词源
2. 简化为 3 行以内的叙述
3. 关联当前词义

**示例**
- `salary 薪水`：来自拉丁语 salarium，古罗马士兵发盐作为酬劳 → 盐钱 → 薪水
- `companion 同伴`：com(一起) + pan(面包) + ion → 一起吃面包的人 → 同伴
- `disaster 灾难`：dis(否定) + aster(星) → 星位不正 → 灾难（古人迷信星象）

**约束边界**
1. 必须使用公认靠谱词源，不可瞎编历史
2. 叙述简短（≤3 行）
3. 复杂词源可简化叙述但保留核心信息

---

### 规则14｜词族联动记忆法（V2 新增）
**定义**：以一个核心词为锚点，展示其派生词（名词/动词/形容词/副词形式），建立词族网络。

**判定条件**：单词存在派生词（同根不同词性）。

**生成逻辑**
1. 找出核心词的派生形式
2. 标注词性变化规律
3. 一组词族联动记忆

**示例**
- `work` 词族：work(工作) → worker(工人) → working(工作中的) → works(作品)
- `beauty` 词族：beauty(美) → beautiful(美丽的) → beautifully(美丽地) → beautify(美化)
- `act` 词族：act(行动) → actor(演员) → action(行动) → active(活跃的) → activity(活动)

**约束边界**
1. 单次输出 3~5 个派生词，避免过载
2. 必须标注词性变化规律（-er 人、-tion 名词、-ly 副词等）
3. 优先展示高频派生词

### 规则16｜TPR身体动作记忆法（V2 新增 · 动词专属）
**定义**：Total Physical Response，通过身体动作模拟单词含义，建立肌肉记忆。

**判定条件**：动作动词、可表演的状态动词。

**生成逻辑**
1. 用身体动作演示单词含义
2. 文案描述动作步骤
3. 鼓励用户跟做

**示例**
- `jump 跳`：双脚用力蹬地，向上跳起 → jump
- `open 打开`：双手做出推开门/掀开盖子的动作 → open
- `carry 搬运`：双手抱重物在胸前，迈步前行 → carry
- `whisper 耳语`：凑近别人耳朵，捂嘴小声说话 → whisper

**约束边界**
1. 仅适用于可表演的动词
2. 文案必须具体描述动作步骤
3. 抽象动词禁用（如 think, know）

### 规则17｜拼读规则记忆法（V2 新增）
**定义**：利用英语拼读规律（Phonics）帮助记忆单词拼写。

**判定条件**：单词符合标准拼读规则。

**常见拼读规则**
1. **Magic E（魔法 E）**：a_e, i_e, o_e, u_e → 使元音读字母本音
   - `cake` /keɪk/：a + e → a 读 /eɪ/
   - `bike` /baɪk/：i + e → i 读 /aɪ/
2. **元音组合**：ai, ee, oa, ou, ea
   - `rain` /reɪn/：ai 读 /eɪ/
   - `see` /siː/：ee 读 /iː/
3. **R 控制音**：ar, er, ir, or, ur
   - `car` /kɑː/：ar 读 /ɑː/
   - `bird` /bɜːd/：ir 读 /ɜː/
4. **辅音组合**：ch, sh, th, ph, wh
   - `chair` /tʃeə/：ch 读 /tʃ/
   - `ship` /ʃɪp/：sh 读 /ʃ/

**约束边界**
1. 不规则拼读单词禁用（如 colonel, choir）
2. 拆解后需清晰标注每段发音
3. 适合初学拼读的儿童

### 规则18｜情绪锚定记忆法（V2 新增 · 创意强化）
**定义**：利用荒诞、反差、幽默、惊悚等强烈情绪做记忆钩子。

**核心原理**：大脑对引发情绪的信息记忆留存率显著高于平淡信息。

**生成逻辑**
1. 识别单词本义
2. 构造一个反差强烈/荒诞的画面
3. 触发用户情绪（笑、惊、奇、喜）

**示例**
- `fragile 易碎的`：想象快递盒上写着 FRAGILE，结果里面装着一颗会爆炸的炸弹 → 你必须轻拿轻放
- `hungry 饥饿的`：想象一个人饿到啃自己的胳膊 → hungry 到 hungry 到饿疯了
- `lazy 懒惰的`：懒到张嘴吃饭都要别人喂 → lazy

**约束边界**
1. 禁用低俗、暴力、负面情绪
2. 优先选择幽默、可爱、惊奇类情绪
3. 画面感必须强，但控制在 1~2 句话内

### 规则19｜记忆宫殿空间记忆法（V2 新增 · 批量专属）
**定义**：将多个单词放置在熟悉的物理空间（如家、教室）的不同位置，建立空间-单词关联。

**判定条件**：批量学习模式，单词数量 ≥5。

**生成逻辑**
1. 选择用户熟悉的空间（卧室、教室、厨房）
2. 按空间顺序放置单词
3. 每个单词与该位置产生联想

**示例**

- 记忆宫殿（我的家）：
  - 门口：tiger 在门口守卫
  - 客厅：elephant 坐在沙发上看电视
  - 厨房：monkey 在偷吃香蕉

**约束边界**
1. 单次单词数 ≤10
2. 必须按空间顺序放置，不可跳跃
3. 适合批量背诵场景

## 5. 创意记忆增强体系（核心新增）
> **目标**：让助记文案不再是套路拼接，而是真正富有创意、个性化、强画面感的记忆体验。

### 5.1 创意记忆五大原则

#### 原则1｜荒诞优于平淡
- 越反常识、越荒诞的画面，记忆留存率越高
- 示例：记忆 `cat 猫`，"猫在沙发上睡觉"是平淡画面；"猫戴着墨镜弹钢琴"是荒诞画面 → 后者更易记

#### 原则2｜多感官叠加
- 同时调动视觉、听觉、动作、嗅觉、情绪
- 示例：记忆 `coffee 咖啡`，"闻到浓郁香气 + 听到煮咖啡咕嘟声 + 看到深褐色液体 + 想到早晨提神" → 多感官叠加

#### 原则3｜个性化锚定
- 鼓励用户将单词与自己的生活/兴趣关联
- 后端可保存用户兴趣标签（运动、动漫、美食、明星），生成时优先调用相关联想素材

#### 原则4｜故事化叙述
- 单词放在 1~2 句话小故事中，比孤立口诀更长效
- 故事须有：人物 + 动作 + 因果

#### 原则5｜差异点高亮
- 形近词、易混词必须**视觉化差异点**（字母象形、加粗、颜色提示）

---

### 5.2 创意拆分升级规则（V2 强化）

#### 5.2.1 合法片段类型清单
创意拆分时，每段必须是以下类型之一：

| 类型 | 示例 | 备注 |
| --- | --- | --- |
| 完整熟词 | fam→family, is, land | 优先选择 |
| 常见字母组合 | -tion, -ing, -ly, -er, -est | 词缀组合 |
| 字母发音片段 | re /riː/, er /ə/, or /ɔː/ | 发音联想 |
| 象形字母 | s 像蛇, t 像伞柄, o 像圆 | 视觉联想 |
| 数字谐音 | 8 →eight/ate, 4 → four/for | 巧用数字 |
| 拼音联想 | da 大, ma 妈, ba 爸 | 慎用，避免母语干扰 |

#### 5.2.2 创意拆分质量自检
1. ✅ 拆分后每段有清晰画面
2. ✅ 拼接成完整故事
3. ✅ 故事与单词本义强相关
4. ✅ 标注"创意拆分"提示
5. ❌ 拆分片段字母顺序不可调换
6. ❌ 拆分片段字母不可删减

#### 5.2.3 多维创意拆分（同一单词多角度）
同一单词可生成多个创意拆分方案，让用户选择最契合的：

**示例：`family /ˈfæməli/ n.家庭**
- 方案A：fam(family家庭) + ily → "家庭"里"ily"（乐意）做事
- 方案B：f(a)ther + (a)nd + m(other) + i + (l)ove + (y)ou → 爸妈我爱你的首字母
- 方案C：fa(发) + mily(米粒) → 发米粒给全家人吃

### 5.3 跨方法组合记忆（V2 新增）

#### 5.3.1 逻辑 + 画面组合
- 词根拆分 + 场景联想
- 示例：`transport 运输` → 词根 trans(跨越) + port(搬运) → 想象卡车跨越大陆搬运货物

#### 5.3.2 谐音 + 拆分组合
- 整体谐音 + 内部拆分
- 示例：`ambulance 救护车` → 整体谐音"俺不能死" + 内部 amb(两边) + ulance → 两边的人喊救命

#### 5.3.3 词源 + 创意组合
- 真实词源 + 趣味延伸
- 示例：`salary 薪水` → 真实词源：盐作酬劳 + 创意延伸：现在工资条上还是"盐值"评分

#### 5.3.4 形近 + 谐音组合
- 拼写对比 + 谐音区分
- 示例：`quite / quiet` → quite 谐音"快特"（特别快），quiet 多 e（e 像人坐着，很安静）

**约束**：联想链不超过 3 步，避免过长。

## 6. 系统调度约束规则（后端核心逻辑）

### 6.1 基础约束
1. 同一个单词不输出同类型多条记忆方案，自动去重
2. 谐音方案若谐音牵强、读音偏差大，直接舍弃
3. 严禁虚构词根、强行无逻辑切割单词
4. 联想文案长度控制：单条文案 20~80 字
5. 黑名单拦截：暴力拆分（如 teacher 强行拆 tea+cher）直接过滤
6. 一组方案须覆盖"逻辑型 + 画面型"两类，不可全是谐音或全是拆分

### 6.2 用户分层动态权重
- **小学生模式**：提升谐音、顺口溜、场景联想、复合词、TPR动作、字母象形权重；降低复杂词根词缀、词源权重
- **初高中/成人模式**：提升词根词缀、形近对比、词中词、词源、词族权重；降低顺口溜、字母象形权重

### 6.3 词性专属调度
- 动作动词：TPR 动作 + 场景联想 ≥1 条
- 具象名词：图像场景 + 字母象形（低龄）≥1 条
- 抽象名词：词根词缀 + 语境造句 ≥1 条
- 形容词：形近对比 + 近反义 ≥1 条
- 功能词：高频搭配 + 语境造句，不强求创意

### 6.4 词长专属调度
- 1~3 字母：禁用词根拆分、复合词拆分；优先场景造句、TPR、字母象形
- 4~6 字母：复合词、词中词、形近对比优先
- 7~10 字母：词根词缀、创意拆分、词源优先
- 11+ 字母：词根词缀 + 创意拆分组合输出

### 6.5 质量门禁
- 所有方案须通过质量评估（见第7章）才能输出
- 不达标的方案直接过滤，不强行凑数
- 若无可输出方案，返回"建议死记硬背 + 高频搭配例句"

## 7. 记忆文案质量评估维度（核心新增）

### 7.1 五维评分（每项 1~5 分）

| 维度 | 1 分 | 3 分 | 5 分 |
| --- | --- | --- | --- |
| **画面感** | 抽象描述 | 有具体物 | 多感官画面 |
| **逻辑性** | 拆分牵强 | 基本通顺 | 严密推导 |
| **趣味性** | 平淡 | 略有趣 | 荒诞幽默 |
| **准确性** | 词义偏差 | 基本准确 | 完全精准 |
| **个性化** | 通用模板 | 适配人群 | 命中用户兴趣 |

### 7.2 合格阈值
- 单条方案总分 ≥15 分（满分25）方可输出
- 优良方案总分 ≥20 分，优先排序
- 低于 15 分的方案直接过滤

### 7.3 一票否决项
- 词义错误 → 直接弃用
- 谐音误导发音 → 直接弃用
- 创意拆分破坏字母顺序 → 直接弃用
- 包含低俗/负面内容 → 直接弃用

  const filtered = dedupAndEnsureCoverage(methods)

  return filtered.slice(0, 3)
}

function classifyWord(word) {
  return {
    length: getLengthCategory(word),       // short/medium/long/xlong
    pos: getPartOfSpeech(word),             // noun/verb/adj/adv/func
    decomposable: getDecomposability(word) // strong/medium/weak/none
  }
}

function matchCandidatesByClass(wordClass, userProfile) {
  let candidates = []
  
  // 按词长调度
  if (wordClass.length === 'short') {
    candidates.push('scene', 'tpr', 'letterPictogram', 'rhyme')
  } else if (wordClass.length === 'medium') {
    candidates.push('compound', 'innerWord', 'similar', 'wordFamily')
  } else if (wordClass.length === 'long') {
    candidates.push('rootAffix', 'creativeSplit', 'etymology')
  }
  
  // 按词性调度
  if (wordClass.pos === 'verb') candidates.push('tpr', 'scene')
  if (wordClass.pos === 'concrete_noun') candidates.push('scene', 'letterPictogram')
  if (wordClass.pos === 'abstract_noun') candidates.push('rootAffix', 'contextSentence')
  if (wordClass.pos === 'adj') candidates.push('similar', 'antonymSynonym')
  
  // 按可拆解性调度
  if (wordClass.decomposable === 'strong') candidates.unshift('rootAffix')
  if (wordClass.decomposable === 'medium') candidates.unshift('compound', 'innerWord')
  if (wordClass.decomposable === 'weak') candidates.push('creativeSplit')
  
  // 用户偏好过滤
  candidates = candidates.filter(c => !userProfile.disabledMethods.includes(c))
  
  return [...new Set(candidates)]
}

function qualityCheck(method) {
  let score = 0
  score += rateImagery(method)        // 1-5
  score += rateLogic(method)          // 1-5
  score += rateFun(method)            // 1-5
  score += rateAccuracy(method)       // 1-5
  score += ratePersonalization(method)// 1-5
  return score
}
